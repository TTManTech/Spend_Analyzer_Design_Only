# Spend Analyzer (design only)

Static landing page for Spend Analyzer, a TTM Tech product: **Know Your Money (KYM)** through your spends, investments and savings.

## Files

| File | What |
| --- | --- |
| `index.html` | The page: logo, title, subtitle and three rate bubbles (Spend, Investment, Savings) |
| `assets/ttm-tech-logo-light.svg` | Logo for light mode |
| `assets/ttm-tech-logo-dark.svg` | Logo for dark mode |

The rate values are placeholders (58% + 24% + 18% = 100%). The page follows the viewer's light/dark setting and uses the TTM Tech palette and JetBrains Mono (Google Fonts).

## Run

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```
